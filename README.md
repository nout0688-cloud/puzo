# Puzo

SoundCloud-плеер для iPhone (SwiftUI, iOS 17+) на базе официального виджета SoundCloud.

## Сборка без Mac
1. Создай пустой репозиторий на GitHub и запушь этот проект в ветку `main`.
2. Открой вкладку **Actions**, дождись зелёной сборки **Build IPA**.
3. Скачай артефакт `Puzo-ipa` → распакуй → `Puzo.ipa`.
4. Подключи iPhone к Windows, открой **Sideloadly**, перетащи `Puzo.ipa`, введи Apple ID, нажми Start.
5. На iPhone: Настройки → Основные → VPN и управление устройством → доверять профилю.
6. Переустанавливай раз в 7 дней (бесплатный Apple ID).

## Использование
Нажми `+` и вставь ссылку на трек/плейлист SoundCloud (из буфера подставится автоматически).
